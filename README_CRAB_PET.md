# Desktop Pet Crab 🦀

A cute pixel-art desktop pet crab for Windows, built with Python and tkinter.

## Features

- **Pixel-art orange crab** with animated eyes, claws, and legs
- **Eye tracking** - eyes follow your mouse cursor
- **Random walking** - crawls left and right along the screen bottom
- **Click reactions** - click the crab for random reactions:
  - Floating hearts
  - Bouncing jump
  - Blushing cheeks
  - Claw waving
- **Idle animations** - wobbles when bored
- **Special actions** - blows bubbles, stretches
- **Draggable** - click and drag to move
- **Always on top**, transparent background, no taskbar icon
- **Right-click menu** to quit

## Requirements

- Python 3.x (with tkinter, included in standard Windows Python)
- Windows (uses Windows-specific transparency attributes)

## Run

```bash
python desktop_pet_crab.py
```

## Controls

| Action | Effect |
|--------|--------|
| Left click | Random cute reaction |
| Left drag | Move the crab |
| Right click | Context menu (About / Quit) |
